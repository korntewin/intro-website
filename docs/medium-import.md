# Publishing the RIIR article on Medium

## Confirmed GitHub Pages output

The Astro build renders all 14 article diagrams from editable SVG files into **real PNG files** using Sharp, and the published article has 14 absolute HTTPS `<img src="...png">` links. The deployed `gh-pages` branch contains the PNG files (each well below Medium's 25 MB image limit).

Medium's automatic import may still reject these images. Medium documents that its importer relies on a third-party service, with no guarantee that every image will transfer. A broken Medium import does **not** prove that an image is SVG or invalid.

## Try automatic import first

1. Use the published page: https://korntewin.github.io/intro-website/blog/riir-rust-prediction-service/
2. On Medium desktop: **Stories > Import a story**, paste the published URL, then edit the draft.
3. Check for missing or rejected images, code blocks, tables, and Thai formatting.

## Reliable fallback when Medium says there is a problem with an image

1. Download **[all 14 PNG images in one ZIP](https://korntewin.github.io/intro-website/blog/medium-images.zip)**.
2. In your existing Medium draft, remove any broken image placeholders and keep the correctly imported text. If the import fails completely, create a new draft and copy the article text from GitHub Pages.
3. Extract the ZIP. Each file starts with its position in the article (`01-`, `02-`, etc.).
4. At the matching paragraph, use Medium's **+ > Image** control or drag and drop **one PNG at a time**. Uploading multiple images at once can cause Medium to create a grid.
5. Check that all 14 images display. For a new manually created draft, set the canonical URL to the GitHub Pages article using Medium's story settings before publication.

This bypasses Medium's unreliable remote image downloader, because the Medium editor uploads the actual PNG bytes from your computer.

## Build details

The PNGs and `public/blog/medium-images.zip` are generated by `npm run dev` and `npm run build` from `public/blog/figures/*.svg`. They are ignored by Git and copied into `dist/blog/` during the Astro build. The PR workflow verifies PNG signatures and ZIP contents.

Medium officially accepts JPG, JPEG, PNG and GIF images of up to 25 MB. It does not promise that importing a remote webpage will always recover images.
